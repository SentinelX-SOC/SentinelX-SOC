# React + TypeScript + Vite

This project uses Vite with React and TypeScript, and ESLint for code quality checks.

## Available scripts

- `npm run dev` — start the Vite development server
- `npm run build` — type-check and build the app
- `npm run lint` — run ESLint against the frontend source

## Notes

This template includes the standard React + Vite setup and keeps the application architecture intact while using ESLint for linting.
